# Scripts for building zvaultio (https://www.zvault.io/)
This files will help building zvaultio as described in the site. Future releases will include ARM64 builds.

## How-to use
- So far the scripts will build up to the ports. Just execut them in the nmerical order.

## Caveats
- In the ports building process 2 ports will fail and 3 will be skipped. Still working on these issues.
